TARHINI’S DOGS · OWNER SETUP

Connect your private store desk.

Your public site stays on GitHub Pages. Supabase stores the menu, team, contact details, and photos. The public repository does not contain your email or private database key.

  1. Create a project at Supabase Dashboard. Keep the database password private; the website does not need it.
  2. Open Supabase SQL Editor, paste the contents of supabase/schema.sql from the repository, and run it.
  3. In Project Settings → API Keys or the Connect dialog, copy the Project URL and publishable key. Never use the secret/service-role key in the website.
  4. Edit supabase-config.js with those two values, then commit and push the change.
  5. In Authentication → URL Configuration, add https://alitarhini-hash.github.io/tarhini-dogs/admin.html to Redirect URLs. Set Site URL to https://alitarhini-hash.github.io/tarhini-dogs/.
  6. Open the owner desk, enter your email, request a sign-in link, and open it in the same browser. This creates your Supabase user but does not yet give editing access.
  7. In Supabase Authentication → Users, copy your user UUID. In SQL Editor, run the following after replacing the placeholder with your UUID:
    update auth.users
set raw_app_meta_data = coalesce(raw_app_meta_data, '{}'::jsonb) || '{"store_owner": true}'::jsonb
where id = 'PASTE-YOUR-USER-UUID-HERE';
  8. Sign out of the owner desk, request a new sign-in link, and sign in again.

The publishable key is safe to use in the browser when row-level security is enabled. Do not publish a database password or secret/service-role key.
